# Corpus 01 — IA Generativa en español

Selección de seis lecciones de Microsoft Generative AI for Beginners. Es el corpus recomendado para
el taller común por su proximidad al programa de IA Generativa y porque permite observar fusiones,
referencias cruzadas y separación por topics.

Topics: `fundamentos-llm`, `gobernanza`, `prompting`, `rag` y `agentes`.
